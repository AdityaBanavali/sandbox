Append Buffer • O(1)

New keystrokes append to an immutable Add buffer. Consecutive typing merges into the active piece without allocating new nodes.

2

Zero-Copy Split • O(P)

Edits in existing text insert piece descriptors pointing to byte offsets. The underlying file buffers remain untouched.

3

Pointer Swap Undo • O(1)

Every keystroke or batch preserves a delta snapshot. Undo/Redo swaps pointer heads in constant time without text copies.
